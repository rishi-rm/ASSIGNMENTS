# Python Pandas Lab Assignment 5

## Objective

Apply Pandas DataFrame operations, statistical analysis, sorting, filtering, and visualization to student academic performance data.

## Software

- Python 3
- Pandas
- Matplotlib

## Installation

Run from this folder:

```powershell
py -3.13 -m pip install -r requirements.txt
```

## Dataset

`student_performance.csv` contains 10 fictional student records with department, attendance, subject marks, and study hours.

## Running the programs

Run each question independently:

```powershell
py -3.13 q1_import_display.py
py -3.13 q2_dataframe_info.py
py -3.13 q3_create_modify_dataframe.py
py -3.13 q4_add_delete_columns.py
py -3.13 q5_statistical_analysis.py
py -3.13 q6_aggregate_functions.py
py -3.13 q7_percentage_change.py
py -3.13 q8_sort_values.py
py -3.13 q9_sort_index.py

py -3.13 q13_line_plot.py

```

Generated charts and CSV files are saved in `outputs/`. Pass in Q3 and Q18 uses Average_Marks >= 40.
